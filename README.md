# LanChat Landing

الصفحة الرسمية لتعريف تطبيق **LanChat** بهوية الفحمي + الذهبي `#C9960F`.

عربي / إنجليزي · شرح المميزات · روابط App Store و Google Play و LanChat Web.

## تشغيل محلي

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

المخرجات في مجلد `dist/`. تشغيل البناء محليًا لا يحدّث الموقع المنشور تلقائيًا.
لا تعتمد على نسخ/رفع `dist` يدويًا للسيرفر.

## Coolify (VPS)

المشروع بدون Docker. في Coolify اختر **Nixpacks** مع:

- Base directory: `lanchat(payment)` إذا كان الريبو `LANCHATFOLDER`، أو جذر المشروع إذا كان ريبو اللاندنج وحده
- Build Pack: **Nixpacks** (ليس Dockerfile، وليس Static فقط بدون build)
- Coolify يشغّل `npm ci` ثم `npm run build` ثم يخدم `dist`

بعد تعديل الكود في `src/`:
1. `git push`
2. من Coolify: **Redeploy** (يفضّل بدون cache إن ظهر الخيار)

مسح `dist` محليًا ثم `npm run build` لا يحدّث السيرفر وحده — التحديث يأتي من push + redeploy.

## أقسام الصفحة وتجربتها

- مقدمة مع نموذج توضيحي متحرك للمحادثات والمكالمات والغرف.
- استكشاف المميزات بقرص تفاعلي يدعم لوحة المفاتيح.
- من نحن، رؤيتنا، رسالتنا، أهدافنا وقيمنا.
- تبويبات للأصدقاء والعائلة والفرق والمجتمعات مع أمثلة توضيحية.
- خطوات البداية، نسخة الويب، أدوات الخصوصية والأسئلة الشائعة.
- التواصل مع الفريق وروابط تحميل التطبيق.
- نسخة عربية باتجاه RTL ونسخة إنجليزية باتجاه LTR، مع حفظ اختيار اللغة محليًا.
- قائمة للموبايل، حركات ظهور عند التمرير، واحترام إعداد تقليل الحركة.

المحتوى التعريفي الجديد في `src/landingContent.ts`، ومحتوى المميزات وروابط المتاجر في `src/content.ts`.
النماذج المرئية أمثلة توضيحية وليست محادثات حقيقية أو لقطات من حسابات مستخدمين.
